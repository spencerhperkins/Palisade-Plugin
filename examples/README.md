# Examples

This folder holds sample outputs from the Palisade skills, run on public patents. Files are named `<skill>-<patent>.md`, for example `prior-art-search-US10XXXXXX.md`, or `<skill>-<topic>.md` for skills that start from a product or technology description.

Each example should include the exact prompt used, the date it was run, and the unedited output. Examples are illustrations, not legal opinions; see [DISCLAIMER.md](../DISCLAIMER.md).
